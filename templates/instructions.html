Language Reference Guide

Review equivalent query and data-processing patterns for SQL and procedural Python before starting the practice tasks.

Illustrative Schema: The examples below use a sample university catalog with two tables: Departments (dept_id, dept_name) and Courses (course_code, title, dept_id, credits, fee).

1. Selection and Filtering (SELECT ... WHERE with Multiple Conditions)

Retrieve specific columns and filter rows using multiple logical conditions connected with AND.

SELECT course_code, title
FROM Courses
WHERE credits = 4 AND fee < 500.0
ORDER BY course_code ASC;

Plain-English summary: This code finds all 4-credit courses with a fee under 500.0, skipping any missing fees, and lists their code and title in alphabetical order.

2. Sorting with Two Columns, Limiting, and Filtering Missing Values

Exclude missing values using IS NOT NULL, sort by multiple columns with DESC and ASC, and restrict rows with LIMIT.

SELECT course_code, fee, credits
FROM Courses
WHERE fee IS NOT NULL AND credits IS NOT NULL
ORDER BY fee DESC, credits ASC
LIMIT 4;

Plain-English summary: This code skips courses with missing fees or credits, sorts the rest from highest fee to lowest, breaks ties by lower credits, and keeps only the top 4 courses.

3. Grouping and Counting (GROUP BY ... COUNT)

Group records by a common key attribute and compute the count of records in each group.

SELECT dept_id, COUNT(*) AS total_courses
FROM Courses
WHERE dept_id IS NOT NULL
GROUP BY dept_id
ORDER BY dept_id ASC;

Plain-English summary: This code counts how many courses belong to each department and lists each department ID alongside its course total in alphabetical order.

4. Combining Two Tables (INNER JOIN)

Combine attributes from two related tables by matching primary and foreign key values.

SELECT c.course_code, c.title, d.dept_name
FROM Courses c
JOIN Departments d ON c.dept_id = d.dept_id
ORDER BY c.course_code ASC;

Plain-English summary: This code looks up each course's department ID to show the course code and title together with the full department name in alphabetical order.

5. Group Aggregation with Average, Rounding, and Threshold (AVG, ROUND, HAVING)

Compute the group average ignoring NULL values, round to 2 decimal places, and filter aggregated groups with HAVING.

SELECT dept_id, ROUND(AVG(fee), 2) AS avg_fee
FROM Courses
WHERE fee IS NOT NULL AND dept_id IS NOT NULL
GROUP BY dept_id
HAVING AVG(fee) >= 350.0
ORDER BY dept_id ASC;

Plain-English summary: This code calculates each department's average fee leaving out missing values, rounds that average to two decimals, and keeps only departments averaging 350.0 or more.

6. Finding Records with No Match (LEFT JOIN ... IS NULL)

Identify parent records that have no matching rows in a child table using a left outer join and testing for IS NULL.

SELECT d.dept_id, d.dept_name
FROM Departments d
LEFT JOIN Courses c ON d.dept_id = c.dept_id
WHERE c.dept_id IS NULL
ORDER BY d.dept_id ASC;

Plain-English summary: This code finds all departments that currently have no courses by checking for department IDs that never appear in the course list, sorted in alphabetical order.

Illustrative Data: The examples below process in-memory lists of dictionaries: departments = [{'dept_id': ..., 'dept_name': ...}] and courses = [{'course_code': ..., 'title': ..., 'dept_id': ..., 'credits': ..., 'fee': ...}].

1. Selection and Filtering (List Comprehension with Multiple Conditions)

Extract specific keys and filter records using multiple conditional expressions connected with and.

# Filter courses with 4 credits and fee below 500.0, skipping missing fees
selected_courses = [
    {'course_code': c['course_code'], 'title': c['title']}
    for c in courses
    if c['credits'] == 4 and c['fee'] is not None and c['fee'] < 500.0
]
selected_courses.sort(key=lambda c: c['course_code'])

Plain-English summary: This code finds all 4-credit courses with a fee under 500.0, skipping any missing fees, and lists their code and title in alphabetical order.

2. Sorting with Two Columns, Limiting, and Filtering Missing Values

Filter out None values, sort using a tuple key (-x for descending), and extract the top items using a slice [:N].

# Exclude missing fees and credits, sort by fee DESC then credits ASC, slice top 4
valid_courses = [c for c in courses if c['fee'] is not None and c['credits'] is not None]
sorted_courses = sorted(
    valid_courses,
    key=lambda c: (-c['fee'], c['credits'])
)
top_courses = sorted_courses[:4]

Plain-English summary: This code skips courses with missing fees or credits, sorts the rest from highest fee to lowest, breaks ties by lower credits, and keeps only the top 4 courses.

3. Grouping and Counting (Dictionary Accumulator)

Count occurrences by group key using a dictionary frequency accumulator, then format the result.

# Count courses per department with a dictionary, skipping missing department IDs
course_counts = {}
for c in courses:
    if c['dept_id'] is not None:
        d = c['dept_id']
        course_counts[d] = course_counts.get(d, 0) + 1

# Format output as sorted list of dictionaries
summary = [
    {'dept_id': d, 'total_courses': cnt}
    for d, cnt in sorted(course_counts.items())
]

Plain-English summary: This code counts how many courses belong to each department and lists each department ID alongside its course total in alphabetical order.

4. Combining Two Lists (Dictionary Lookup)

Index parent records into a lookup dictionary by primary key to merge fields from two lists in linear time.

# Build a lookup dictionary for departments
dept_lookup = {d['dept_id']: d['dept_name'] for d in departments if d['dept_id'] is not None}

# Combine course records with department names
combined = [
    {
        'course_code': c['course_code'],
        'title': c['title'],
        'dept_name': dept_lookup[c['dept_id']]
    }
    for c in courses
    if c['dept_id'] is not None and c['dept_id'] in dept_lookup
]
combined.sort(key=lambda c: c['course_code'])

Plain-English summary: This code looks up each course's department ID to show the course code and title together with the full department name in alphabetical order.

5. Group Aggregation with Average, Rounding, and Threshold (Dictionary of Lists)

Group values into a dictionary of lists excluding None, compute rounded averages, and filter with a threshold.

# Group non-missing fees by department
dept_fees = {}
for c in courses:
    if c['dept_id'] is not None and c['fee'] is not None:
        dept_fees.setdefault(c['dept_id'], []).append(c['fee'])

# Compute rounded average and filter threshold >= 350.0
avg_summary = []
for d, fees in dept_fees.items():
    mean_val = round(sum(fees) / len(fees), 2)
    if mean_val >= 350.0:
        avg_summary.append({'dept_id': d, 'avg_fee': mean_val})

avg_summary.sort(key=lambda x: x['dept_id'])

Plain-English summary: This code calculates each department's average fee leaving out missing values, rounds that average to two decimals, and keeps only departments averaging 350.0 or more.

6. Finding Records with No Match (Set Membership Anti-Join)

Collect keys from the child list into a set, then retain parent records whose keys are not in the set.

# Collect unique department IDs that have at least one course
active_dept_ids = {c['dept_id'] for c in courses if c['dept_id'] is not None}

# Filter departments with no match using set membership
inactive_depts = [
    {'dept_id': d['dept_id'], 'dept_name': d['dept_name']}
    for d in departments
    if d['dept_id'] is not None and d['dept_id'] not in active_dept_ids
]
inactive_depts.sort(key=lambda d: d['dept_id'])

Plain-English summary: This code finds all departments that currently have no courses by checking for department IDs that never appear in the course list, sorted in alphabetical order.
