Language Reference Guide

Review equivalent query and data-processing patterns for SQL and procedural Python before starting the practice tasks.

Illustrative Schema: The examples below use a sample university catalog with two tables: Departments (dept_id, dept_name) and Courses (course_code, title, dept_id, credits).

1. Selection and Filtering (SELECT ... WHERE)

Retrieve specific columns and filter rows using a conditional predicate.

SELECT course_code, title
FROM Courses
WHERE credits = 4;

2. Sorting and Limiting (ORDER BY ... LIMIT)

Sort records by an attribute in descending or ascending order and take the top N rows.

SELECT course_code, title, credits
FROM Courses
ORDER BY credits DESC
LIMIT 3;

3. Grouping and Counting with Threshold (GROUP BY ... HAVING)

Group rows by a common key, calculate aggregate counts, and retain groups satisfying a threshold.

SELECT dept_id, COUNT(*) AS course_count
FROM Courses
GROUP BY dept_id
HAVING COUNT(*) >= 3;

4. Combining Two Tables (INNER JOIN)

Combine attributes from two related tables by matching foreign key values.

SELECT c.course_code, c.title, d.dept_name
FROM Courses c
JOIN Departments d ON c.dept_id = d.dept_id;

5. Finding Records with No Match (LEFT JOIN ... IS NULL)

Find parent records that have no matching entries in a related table via an anti-join pattern.

SELECT d.dept_id, d.dept_name
FROM Departments d
LEFT JOIN Courses c ON d.dept_id = c.dept_id
WHERE c.course_code IS NULL;

Illustrative Data: The examples below process data represented as lists of dictionaries: departments = [{'dept_id': ..., 'dept_name': ...}] and courses = [{'course_code': ..., 'title': ..., 'dept_id': ..., 'credits': ...}].

1. Selection and Filtering (List Comprehension with if)

Extract specific keys and filter elements using a conditional comprehension.

# Select course code and title for all 4-credit courses
four_credit_courses = [
    {'course_code': c['course_code'], 'title': c['title']}
    for c in courses
    if c['credits'] == 4
]

2. Sorting and Limiting (sorted() and Slicing [:N])

Sort dictionaries with a key lambda and take the first N items using Python list slicing.

# Order courses by credits descending and take the first 3
sorted_courses = sorted(courses, key=lambda c: c['credits'], reverse=True)
top_three_courses = sorted_courses[:3]

3. Grouping and Counting with Threshold (Dictionary Accumulation)

Count occurrences by key using a dictionary accumulator and retain groups meeting the threshold.

# Count courses per department with a dictionary
counts = {}
for c in courses:
    d = c['dept_id']
    counts[d] = counts.get(d, 0) + 1

# Keep departments with at least 3 courses
popular_depts = [
    {'dept_id': d, 'course_count': cnt}
    for d, cnt in counts.items()
    if cnt >= 3
]

4. Combining Two Lists (Dictionary Lookup)

Index parent records into a lookup map to combine matching fields from two lists in linear time.

# Build a lookup dictionary for departments
dept_lookup = {d['dept_id']: d['dept_name'] for d in departments}

# Combine course records with department names
combined = [
    {
        'course_code': c['course_code'],
        'title': c['title'],
        'dept_name': dept_lookup[c['dept_id']]
    }
    for c in courses
    if c['dept_id'] in dept_lookup
]

5. Finding Records with No Match (Set Membership Anti-Join)

Collect keys from child records into a set, then retain parent records whose keys are not in the set.

# Collect department IDs that have at least one course
offered_dept_ids = {c['dept_id'] for c in courses}

# Filter departments with no match using set membership
inactive_depts = [
    {'dept_id': d['dept_id'], 'dept_name': d['dept_name']}
    for d in departments
    if d['dept_id'] not in offered_dept_ids
]
