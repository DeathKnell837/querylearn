Language Reference Guide

Review the syntax for SQL and Python before starting the practice tasks.

SQL Basic Syntax

SQL is a declarative language used to query databases. The basic structure of a query involves selecting columns from tables and optionally filtering, grouping, or ordering the results.

SELECT and FROM

SELECT student_name, year_level
FROM Students;

WHERE (Filtering)

SELECT *
FROM Courses
WHERE credits > 3;

JOIN (Combining Tables)

SELECT s.student_name, c.course_name
FROM Students s
JOIN Enrollments e ON s.student_id = e.student_id
JOIN Courses c ON e.course_id = c.course_id;

GROUP BY and HAVING (Aggregation)

SELECT student_id, COUNT(course_id) AS total_courses
FROM Enrollments
GROUP BY student_id
HAVING COUNT(course_id) > 2;

ORDER BY and LIMIT

SELECT course_name, credits
FROM Courses
ORDER BY credits DESC
LIMIT 5;

Python Data Processing

In Python, you will process data represented as lists of dictionaries. Each dictionary corresponds to a row in a table.

List Comprehensions (Basic Select/Map)

# Extracting names from a list of student dictionaries
names = [s['student_name'] for s in students]

Filtering with For Loops

# Getting courses with more than 3 credits
heavy_courses = []
for c in courses:
    if c['credits'] > 3:
        heavy_courses.append(c)

List Comprehensions with Filtering

# Same as above, but more concise
heavy_courses = [c for c in courses if c['credits'] > 3]

Sorting with Lambda Functions

# Sort courses by credits in descending order
sorted_courses = sorted(courses, key=lambda x: x['credits'], reverse=True)

Aggregation Functions

# Counting elements (len)
total_students = len(students)

# Summing values
total_credits = sum(c['credits'] for c in courses)

# Finding maximum
max_credits = max(c['credits'] for c in courses)
