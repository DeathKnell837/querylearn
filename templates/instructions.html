Language Reference Guide

Read the examples in both tabs. They show the same six ideas in two ways.

About the examples: They use two small tables of school courses: Departments (dept_id, dept_name) and Courses (course_code, title, dept_id, credits, fee). An empty value is called NULL.

1. Pick rows that match

SELECT course_code, title
FROM Courses
WHERE credits = 4 AND fee < 500.0
ORDER BY course_code ASC;

What it does: Shows courses that have 4 credits and cost less than 500, sorted by course code.

2. Sort and keep the top few

SELECT course_code, fee, credits
FROM Courses
WHERE fee IS NOT NULL AND credits IS NOT NULL
ORDER BY fee DESC, credits ASC
LIMIT 4;

What it does: Skips empty values, puts the highest fee first, and keeps only the first 4 rows.

3. Count items in each group

SELECT dept_id, COUNT(*) AS total_courses
FROM Courses
WHERE dept_id IS NOT NULL
GROUP BY dept_id
ORDER BY dept_id ASC;

What it does: Counts how many courses each department has.

4. Combine two tables

SELECT c.course_code, c.title, d.dept_name
FROM Courses c
JOIN Departments d ON c.dept_id = d.dept_id
ORDER BY c.course_code ASC;

What it does: Matches each course to its department so you can see the department name next to the course.

5. Find the average of each group

SELECT dept_id, ROUND(AVG(fee), 2) AS avg_fee
FROM Courses
WHERE fee IS NOT NULL AND dept_id IS NOT NULL
GROUP BY dept_id
HAVING AVG(fee) >= 350.0
ORDER BY dept_id ASC;

What it does: Finds each department's average fee, rounds it, and keeps only averages of 350 or more.

6. Find items with no match

SELECT d.dept_id, d.dept_name
FROM Departments d
LEFT JOIN Courses c ON d.dept_id = c.dept_id
WHERE c.dept_id IS NULL
ORDER BY d.dept_id ASC;

What it does: Shows departments that have no courses at all.

About the examples: They use two lists of school courses: departments = [{'dept_id': ..., 'dept_name': ...}] and courses = [{'course_code': ..., 'title': ..., 'dept_id': ..., 'credits': ..., 'fee': ...}]. An empty value is called None.

1. Pick rows that match

result = []
for c in courses:
    if c['credits'] == 4 and c['fee'] is not None and c['fee'] < 500.0:
        result.append((c['course_code'], c['title']))
result.sort()

What it does: Keeps courses that have 4 credits and cost less than 500, sorted by course code.

2. Sort and keep the top few

good = [c for c in courses if c['fee'] is not None and c['credits'] is not None]
good.sort(key=lambda c: (-c['fee'], c['credits']))
top4 = good[:4]

What it does: Skips empty values, puts the highest fee first, and keeps only the first 4 items.

3. Count items in each group

counts = {}
for c in courses:
    if c['dept_id'] is not None:
        d = c['dept_id']
        counts[d] = counts.get(d, 0) + 1
result = sorted(counts.items())

What it does: Counts how many courses each department has.

4. Combine two lists

names = {d['dept_id']: d['dept_name'] for d in departments}
result = [
    (c['course_code'], c['title'], names[c['dept_id']])
    for c in courses if c['dept_id'] in names
]
result.sort()

What it does: Matches each course to its department so you can see the department name next to the course.

5. Find the average of each group

fees = {}
for c in courses:
    if c['dept_id'] is not None and c['fee'] is not None:
        fees.setdefault(c['dept_id'], []).append(c['fee'])
result = []
for d in sorted(fees):
    avg = round(sum(fees[d]) / len(fees[d]), 2)
    if avg >= 350.0:
        result.append((d, avg))

What it does: Finds each department's average fee, rounds it, and keeps only averages of 350 or more.

6. Find items with no match

used = {c['dept_id'] for c in courses if c['dept_id'] is not None}
result = sorted(
    (d['dept_id'], d['dept_name'])
    for d in departments if d['dept_id'] not in used
)

What it does: Shows departments that have no courses at all.
