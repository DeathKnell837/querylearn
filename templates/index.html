Research Instrument

QueryLearn

Evaluating SQL Readability and Productivity Among Novice Database Learners

An empirical investigation comparing Domain-Specific Languages (SQL) and General-Purpose Languages (Procedural Python) for database query comprehension and development.

Start Evaluation Researcher Portal

Evaluation Architecture

6 Balanced Tasks

Equivalent query constructs ranging from simple selections to relational multi-table joins and aggregations.

Automated Timing

Precise measurement of task completion times, attempt counts, and edit frequencies within bounded intervals.

Hidden Test Oracles

Solutions are verified against multiple test datasets to guarantee correctness across edge cases.

Code Interpretation

Dedicated reading and prediction assessments to objectively measure semantic readability and mental overhead.

Psychometric Survey

Standardized 5-point Likert measures evaluating perceived syntax clarity, debugging friction, and learner preference.

Anonymized Telemetry

Strict participant anonymization with randomized counterbalanced assignment protocols.
